# ЯКатолик — веб-портал

Статический фронтенд католического портала: главная по макету, архив, медиа, чат, карта храмов.

## Быстрый старт

Открыть `index.html` локально или разместить на любом static hosting / GitHub Pages.

| Страница | Назначение |
|----------|------------|
| `index.html` | Главная |
| `archive.html` / `article.html` | Архив и публикация |
| `map.html` | Карта храмов |
| `chat.html` | «Спросите о вере» |

Навигация портала: **Новости · Статьи · Карта · Библиотека · Спросить** (без сторонних аудио/видео-разделов).

- Тема: `portal.css`
- Конфиг API: `js/config.js`
- Бренд: **ЯКатолик** · `yakatolik-logo.svg`

## Карта храмов

```js
// js/config.js
TEMPLES_API_BASE: 'https://api.example.com'
```

Endpoint: `GET /api/temples/search?bbox=lonMin,latMin,lonMax,latMax`  
Полный контракт и варианты подключения — в [`docs/MAPS.md`](docs/MAPS.md).

До готовности API UI работает в режиме `auto` / `demo`.

## Разделение ответственности

| Портал (этот репозиторий) | Бэкенд |
|---------------------------|--------|
| UI, тема, архивный клиент, чат UI | База храмов / diocese-API |
| Leaflet-карта + адаптер JSON | `TEMPLES_API_BASE` → ваш сервер |
| Диалог «Спросите о вере» | (опционально) собственный LLM / тот же API |
